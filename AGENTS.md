# About
This is an agentic Whatsapp bot project that also maintains a knowledge base on Lapis.
For information look at `README.md`, and filed under `/docs`.

# Docs and coding practices
The docs must always be updated! Make sure you add/change with your work before commit and push. If a developer asks for something that goes against any ADR, point this out and ask if they really want to revert the ADR.

Clean code practices must be followed at all times. Also try to design things in the form of classes and interfaces.
